🚀 DEMO MODE - This is a preview of the Telegram Mini App

🎯 Demo Features:

  • Fill Sample URL: Automatically fills a sample Uber Eats group cart URL
  • Simulate Processing: Shows the complete loading flow with progress steps
  • Show Success/Error: Demonstrates toast notifications
  • Clear All: Resets the form and recent carts
  • Custom URL: Test with your own Uber Eats group cart URL

Note: This demo runs in browser mode. In Telegram, it will integrate with the Telegram WebApp API for enhanced functionality.
